# Pocket Budget CLI

A simple, local-first command line tool to track your daily expenses and income.

## Features
- Set and track your overall balance.
- Log transactions with descriptions and categories.
- View a formatted history of all spending.
- No database setup required (uses a local JSON file).

## Installation
1. Clone the repository.
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Run the application:
   ```bash
   python budget.py
   ```
